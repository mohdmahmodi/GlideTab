Privacy

Last updated October 12, 2026.

The app

  • GlideTab has no account, no analytics and no crash reporting.
  • Window titles, browser tab titles and addresses, and window thumbnails are read only to show them in the switcher. They stay in memory and are never written to disk or sent anywhere.
  • The only network request is the update check to the GitHub Releases API, at most once a day. It sends no information about you or your Mac beyond what any web request includes. You can turn it off in Settings, General.
  • Your settings are stored on your Mac in the standard macOS preferences file for GlideTab.

Permissions

  • Accessibility is used to read the shortcut keys and to bring windows to the front.
  • Screen Recording is used for thumbnails and the full-size preview.
  • Automation is used to read and switch browser tabs, and macOS asks once for each browser.

This website

  • The site uses no cookies, analytics or trackers.
  • It is hosted on Cloudflare Pages, which keeps standard server logs. Scripts for the animations load from cdnjs, also run by Cloudflare.
  • Downloads come from GitHub Releases.
