Pick a look.

Thumbnails for the full picture, app icons like the Dock, or a compact list. In Auto size, previews grow when only a few windows are open.

Every window gets its own spot.

The built-in ⌘Tab switches between apps. GlideTab lists windows, so two browser windows are two choices.

  • Windows on other Spaces and displays are included.
  • Minimized windows and hidden apps can be shown, hidden, or listed last.
  • A small badge tells you where each window is.

Type to find any window or tab.

The search field is always there. Type part of a title or an app name and the list narrows as you go. Open tabs in Safari, Chrome, Brave, Edge, Vivaldi, Firefox and Zen show up too, in every Chrome profile.

Questions

Is GlideTab really free?

Yes. There's no paid version, no trial and no account. The source code is on GitHub under the MIT License.

Which Macs does it run on?

Any Mac with macOS 14 Sonoma or later, with Apple silicon or an Intel processor.

Why does it ask for Accessibility and Screen Recording?

Accessibility lets GlideTab read the shortcut keys and bring a window to the front. Screen Recording is for the thumbnails and the full-size preview. The App Icons and List styles work without it.

Can it replace ⌘Tab?

Yes. Set one of your shortcuts to ⌘ Command and Tab. GlideTab turns the built-in switcher off while it runs and turns it back on when you quit.

Is it on the Mac App Store?

No. App Store apps run in a sandbox that doesn't allow switching to a specific window on another Space, which is the main thing GlideTab does. Downloads here are signed and notarized by Apple.

How do I uninstall it?

Quit GlideTab from its menu bar icon, then move it from Applications to the Trash. If it's still listed in System Settings under General, Login Items, remove it there.
